Agent Threads · defect · fixed in PR 33

A turn with hundreds of steps opens without the banner

Real frames from Herdr 0.1.15 in an isolated test window on the mini. The session is synthetic: turn #4 has 300 steps, 150 of them interim texts in Markdown with code blocks and tables. Both runs press the same things: click turn #4, then click the twistie in "Worked for 40m 03s". Click any frame to open it full size. The arrow keys step through them and Esc closes.

The recordings

Frame by frame

Cause

  • Herdr runs a mod's drawing as a script with a time limit, about 50 ms a draw on the mini. Past it the script is stopped ("interrupted") and Herdr keeps the last frame that worked.
  • Since PR 33 an open turn's work lists each interim text as a row. Every rebuild of the rows ran the link rules and the Markdown height estimate over every one of those texts again, with no time guard. With 150 Markdown texts the rebuild never finished, so every later draw stopped too.
  • The hidden probe that measures text also drew every unmeasured part in one frame.

Fix

  • The linked text and the height estimate are kept per text, so a rebuild does not redo them.
  • New texts share the time budget reshaping already has (12 ms). Past it a text shows as written with a rough height for a frame, and the next frame finishes it.
  • The probe measures at most 16 parts a frame, nearest the top of the pane first.
  • A test opens a turn with 150 interim texts and checks the budget, the kept results and the probe's limit. It fails on the old code.
  • No notice or hint appears anywhere.
