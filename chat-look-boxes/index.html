Code and output boxes scroll, and known output is coloured

The owner asked for scrollable code boxes, and colour where the type is known. Real frames from Herdr 0.1.15 in an isolated test window on the mini, on a synthetic session. For the colour frames, turn #7's reply gained one fenced block per language and its last command's output was made JSON. The test window has no wheel, so the frames show what the boxes hold and how they are drawn, not the scrolling itself. Click any frame to open it full size. The arrow keys step through them and Esc closes.

What changed

  • A call's output shows every line it holds, up to 400, in a box 12 lines tall that scrolls down and sideways inside. Long lines are not cut, and there is no Show all. Past 400 lines, a dim line under the box says it holds the first 400.
  • Output that is JSON, a diff, or a file read whose path has a known extension is shown in Herdr's read-only editor with the theme's colours. A file read that Claude Code numbered line by line stays plain, since the numbers would be coloured as code.
  • A call row's command scrolls sideways in place of an ellipsis.
  • Reply code blocks no longer wrap: a long line scrolls sideways inside the block, which still shows up to 12 lines and scrolls inside past that.
  • Herdr colours ts and js, json, yaml, bash and sh, python, rust, go, html, css and sql. Diff and any other language show plain.
  • While the pointer is over a box, the wheel scrolls the box, not the list.

Left for the owner to check by hand

  • Open a call's output with long lines and scroll sideways in the box.
  • Scroll the list with the wheel and pass over a box: say whether the box catching the wheel gets in the way.
