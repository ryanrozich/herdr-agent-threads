Compact Pinned rows

Each pin in the Pinned column and the narrow Pinned view is now a compact row, so five pins fit in a 240 to 320 px column at a 1150 px window. Shots are of the synthetic acme-web session in an isolated test window. Before is PR 19 at 2f9afe5 (pins in time order); after is this branch. Click any shot to open it full size; arrow keys step through them and Esc closes.

What to test

  1. Install. cd ~/herdr-agent-threads-try && git fetch && git checkout pin-compact && git pull && ./install.sh. This branch stacks on PR 19 (pins in time order), so it has that change too.
  2. Five pins. Pin five turns with p, from more than one day if you have a long session. In the Pinned column each is a compact row, and all five show without scrolling.
  3. Open one. In the column, select a pin and press Enter, click it, or press its digit. It opens as the full card, as before. Esc or a second click closes it back to its row.
  4. Selection and new replies. ↑ ↓ move between pins with the usual fill and bar. A pinned turn that gets a reply you have not read shows a small dot at the right of its top line until you open it.
  5. Narrow pane. Make Threads narrower than 480 px and press v. The pins show in the same pane with the same compact rows.
  6. Day pills. The day pills from PR 18 stay, one per day, oldest day first.
