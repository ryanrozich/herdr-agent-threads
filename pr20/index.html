An open turn shows the whole reply

No more Show full reply: an open turn shows all of its reply, and a long one ends in a quiet Collapse (Esc) row. Shots are of the synthetic acme-web session in an isolated test window, with the debug timings on in the header (needed to scroll the window to the end). Before is main at a67b7dd; after is this branch. Click any shot to open it full size; arrow keys step through them and Esc closes.

What to test

  1. Install. cd ~/herdr-agent-threads-try && git fetch && git checkout open-whole-reply && git pull && ./install.sh. This branch starts from main, so it does not have the Pinned time order (PR 19) until one of the two merges.
  2. A long reply. Open a turn with a long answer (Enter). The whole reply shows, with no Show full reply row, and the top of the pane is the turn's head.
  3. The end. Scroll to the end of the reply. A quiet Collapse row with Esc beside it sits under the last paragraph. A short reply has no such row.
  4. Collapse. Press Esc, or click Collapse. The turn closes and its row stays selected and in view; ↓ goes to the next turn.
  5. Long prose. On a reply with a long run of prose and no code block, nothing shows as plain text and nothing is missing. A drag selects across paragraphs, but stops where the reply is split into blocks, about every 3,500 characters.
  6. Pins. A pin you return to opens its turn with the whole reply, at the place you left it, as before.
