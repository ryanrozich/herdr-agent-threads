Agent Threads · chat look · batch 1 · PRs 29 to 32

The quiet turn, the pill, the rail and level 1

Each pair puts the branch before a PR beside the branch with it. All shots come from Herdr 0.1.15 in an isolated test window on the mini, running each branch's mod on a synthetic acme-web session (made-up prompts, replies and tool output). The session's last turn is running, so every shot ends with it. The panel is 560 px wide and the shots are cropped to it. Click any shot to open it full size; the arrow keys step through them and Esc closes.

What to try

  1. Install the stack top. cd ~/herdr-agent-threads-try && git fetch && git checkout level-1 && ./install.sh (PR 32, which holds 29 to 31 too). Open a Claude Code session with some history.
  2. The quiet turn (PR 29). Each turn is your bubble, a "Worked for" line and the reply. Point at a message: its time and icons show. Select a turn with ↑ ↓: its time and icons stay. In settings, "Always show time" keeps the time under every bubble.
  3. The pill (PR 30). Scroll up. "Jump to latest" floats at the bottom centre while the end is off screen; click it or press End.
  4. The rail (PR 31). The right edge has one tick per turn instead of the scrollbar, with a mark for the selected turn and the running turn. It is there in the outline too (o).
  5. Level 1 (PR 32). Open a turn, then click its "Worked for" line: it opens to the tool calls by kind (reads, searches, edits, commands) and the numbers. The running turn says "Working for 0:54".

Notes on the shots

  • Hover cannot be driven on the rig: this Herdr build has no pointer input for tests. The selected turn shows the same reveal a hover does, so the hover pair uses selection.
  • The test window shows a small timing chip in the header only when the panel runs with its test-only debug setting. It is hidden in these shots so the header looks as it does for you; nothing else in the mod was changed.
  • The pasted-image tiles in turns 2 and 5 are empty boxes because the synthetic session has no image files behind them.
  • Nothing is merged. A go for this batch merges PRs 29 to 32 in order.
