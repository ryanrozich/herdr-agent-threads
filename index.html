Agent Threads chat look

The chat look with the four picks you approved, plus everything asked for since: softer bubble colours, bigger image tiles, names over each message, reading type for messages and replies, and the Pinned column as the way to your pins. It is draft PR 8, based on main now that pinning is merged. Nothing merges until you say so.

Every screenshot is from an isolated Herdr window on the mini, with a made-up session. Click any image to open it full size. Arrow keys step through, Esc closes.

The Pinned column

You met the in-pane switch, not the column: the column needed Threads 600 px wide, and the header's list icon did not say what it did. Now the column is the way in.

  • It opens by itself. Your first pin opens the Pinned column beside Threads, and so does opening Threads on a session that already has pins. The keyboard stays in Threads. If you close the column it stays closed until you press v or click Pinned. Closing Threads closes the column too, and opening Threads again brings both back.
  • It fits your widths. The column lists pins, so it is narrow: about a third of the Threads width, 240 to 320 px. It opens whenever Threads is at least 480 px wide, so a 500 px pane counts. Herdr takes the column's room from the terminal side, so Threads keeps its width (the shots at 500, 700 and 960 px below).
  • A labelled button. The list icon is now a button that reads Pinned 2, with your pin count. It opens the column, or goes to it when it is open, and has an accent border while the column is open. In the column the button reads All turns and goes back. v does the same as the button.
  • Under 480 px there is no room, so the pins show in the same pane and a note says "Pinned shows here: the Pinned column needs Threads 480 px wide".

Reading type

Your screenshot showed replies running 140 to 150 characters a line at 960 px, in small grey text on tight lines. Message and reply text is now a step above the labels, on lines 1.5 times its size, and a line stops at about 70 characters however wide the pane is. Names, times, the stats line and Show more keep their small sizes. Replies use the text colour, not the muted grey.

Softer bubble colours

Slate (#47648F) for your messages and plum (#715C91) for agent messages, both with white text at 6.0:1 and 5.8:1. Pick another in settings; Reset to defaults puts these back. The bright blue and purple are still there as presets.

Bigger images

Pasted images are tiles over your bubble, on the right, side by side: about a third of the bubble's width (56 to 120 px), rounded, with a thin border. They shrink in a narrow pane. A click on a tile opens that image full size under the tiles, and its tile gets a ring.

Names

Your messages say "You", or whatever you type in settings under Your name. The reply carries the agent's name where the agent records one, else "Agent". Agent messages keep naming their sender.

The rest of the look

Try it

  1. Install the branch:
    cd ~/herdr-agent-threads-try && git fetch && git checkout chat-look && git pull && ./install.sh
  2. Close the Threads pane and open it again with Cmd-Shift-T.
  3. Widen the pane. Replies and bubbles stop at about 70 characters a line.
  4. Press Enter on a long turn to open it. Click an image tile to see it full size.
  5. Press , for settings. Try Text size, the colours and Your name. Reset to defaults puts back 14 px, slate, plum and You.
  6. Make Threads at least 480 px wide, select a turn and press p. The Pinned column opens beside Threads, and the keyboard stays in Threads. Pin a second turn: it shows in the column, and the header button reads Pinned 2.
  7. Click Pinned 2 or press v to go to the column. There ↑ ↓ move between pins, Enter opens one, and All turns or v goes back.
  8. Close Threads and open it again with Cmd-Shift-T: the column comes back with it, because the session has pins.

A settings file saved by an earlier build of this branch holds that build's colours (blue and purple), because a save writes every value. Reset to defaults switches to slate and plum.

Notes for review

  • Paragraph spacing inside a reply is Herdr's own: 30 px from line to line across a paragraph break, 1.45 times the 21 px line, just under SC 1.4.8's 1.5. A reply block is one list item so a drag can select across its paragraphs, and the mod cannot change spacing inside it.
  • Herdr draws an open reply's Markdown with the line height its box sets: 21 px measured at 14 px.
  • An open turn on a coloured bubble shows your message as plain text. Herdr draws Markdown in the theme's text colour whatever the bubble says. Link rules and code spans in your message show only with plain.
  • Two departures from the design: the action bar stays as buttons, and the side padding is 16 px rather than 12, to line up with the rest of the pane.
  • The README screenshots still show the old look. New images in the repo need your approval first, so they wait until you approve this look.
  • The column opening by itself is the pick for "make the column the main way in". If you would rather it waited for v, that is a small change, or a setting.
  • Quote tracking comes next, as its own PR.
