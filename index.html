Antigravity and Amp in Threads

Threads now reads Antigravity's CLI (agy) and Amp, and every agent shows its own mark. This is draft PR 10 on main, separate from the chat look in PR 8. Nothing merges until you say so.

310 tests pass CI green: Biome, shellcheck, jq, private scan, gitleaks agy 1.5.3 and Amp 0.0.1794 tried live

The screenshots come from an isolated Herdr window on the mini, using made-up sessions. The live tests on your laptop used throwaway sessions in a scratch folder. Click any image to open it full size. Arrow keys step through the images, and Esc closes.

Antigravity

  • agy writes each conversation to ~/.gemini/antigravity-cli/brain/<id>/.system_generated/logs/transcript_full.jsonl. The ~/.gemini/antigravity folder belongs to the older IDE.
  • Each step records a time to the second, input, cached and output tokens, and the tools it called. The prompt step records the model you picked and its level, such as "Gemini 3.5 Flash · Medium".
  • agy keeps the conversation's folder open, so Threads finds the exact conversation for each terminal.

Amp

  • Amp keeps its threads on its own server. On disk it writes only a debug log for each thread and a note of the last thread it ran in each folder.
  • Threads watches that log. When the log grows, Threads reads the thread with Amp's own amp threads export, using the login Amp already has. The export changes nothing and takes about 1.5 s. This makes Amp the one agent Threads reads over the network, and the README now says so.
  • The export holds prompts, replies, tool names, the model, input, output and cache tokens, times to the millisecond, and the thread's title.
  • Threads takes amp threads continue <id> from the command line when it is there. Otherwise it takes the thread Amp last ran in the terminal's folder after that Amp started. When two Amp terminals share a folder, Threads guesses and offers Choose.

Every agent's mark

The marks are the icons Herdr itself ships for these agents: LobeHub icons (MIT) and Pi's own mark. The drawings are unchanged, and ICONS.md records each one's source and license. One-colour marks are drawn white and full-colour marks as they come, both on Herdr's dark tile, which matches Herdr's own settings. Claude keeps its orange tile.

What I could not read

  • Amp, two terminals in one folder: Amp records one last thread per folder, plus a second hash I could not decode, so Threads guesses.
  • Amp offline or logged out: the read fails and says so.
  • Pasted images: neither agent stores one in a form Threads can read.
  • Antigravity's conversation_summaries.db would not open read-only. Threads does not need it.
  • The "isn't supported yet" list: it now shows all seven marks (the large sheet above shows the same files). I could not get the mini's Herdr to treat a stand-in program as an unsupported agent, so there is no screenshot of that state.

Try it

  1. Check out the branch and install: git checkout agents-agy-amp && ./install.sh in your herdr-agent-threads clone.
  2. Run agy in a Herdr terminal, send one prompt, and press Cmd-Shift-T. The badge shows the Antigravity mark, and the turn shows its tokens and model.
  3. Do the same with amp. The first read takes about a second and a half.
  4. Open Threads beside Codex, OpenCode, Pi or Cursor to see their marks in the badge.
