Antigravity and Amp in Threads

Threads now reads Antigravity's CLI (agy), and every agent shows its own mark. Amp is no longer supported, as you asked: an Amp terminal gets a page that says why and links to the README. This is draft PR 10 on main, separate from the chat look in PR 8. Nothing merges until you say so.

307 tests pass CI green: Biome, shellcheck, jq, private scan, gitleaks agy 1.5.3 tried live

The screenshots come from an isolated Herdr window on the mini, using made-up sessions. The live tests on your laptop used throwaway sessions in a scratch folder. Click any image to open it full size. Arrow keys step through the images, and Esc closes.

Antigravity

  • agy writes each conversation to ~/.gemini/antigravity-cli/brain/<id>/.system_generated/logs/transcript_full.jsonl. The ~/.gemini/antigravity folder belongs to the older IDE.
  • Each step records a time to the second, input, cached and output tokens, and the tools it called. The prompt step records the model you picked and its level, such as "Gemini 3.5 Flash · Medium".
  • agy keeps the conversation's folder open, so Threads finds the exact conversation for each terminal.

Amp: not supported, and why

Amp reading is gone: its reader, the amp threads export call, its tests and the text that listed it. Amp keeps its conversations on its own servers, not on disk, so reading them meant calling Amp over the network on every refresh, and Threads reads only local files.

  • In an Amp terminal, Threads shows Amp's mark, "Amp isn't supported", one line of why ("Amp keeps its chats online, on Amp's servers, so Threads cannot read them."), and a Why Amp isn't supported button.
  • The button opens the README's new section, Why Amp isn't supported, which says the same in three plain sentences.
  • Amp is out of the supported list everywhere: the README table, the "isn't supported yet" list for other agents, and the docs.

Every agent's mark

The marks are the icons Herdr itself ships for these agents: LobeHub icons (MIT) and Pi's own mark. The drawings are unchanged, and ICONS.md records each one's source and license. One-colour marks are drawn white and full-colour marks as they come, both on Herdr's dark tile, which matches Herdr's own settings. Claude keeps its orange tile.

What I could not read

  • Pasted images: Antigravity stores none in a form Threads can read.
  • Antigravity's conversation_summaries.db would not open read-only. Threads does not need it.
  • The "isn't supported yet" list for other agents Herdr knows shows the six supported marks. I could not get the mini's Herdr to treat a stand-in program as an unknown agent, so there is no screenshot of that list. The Amp page above is found by the program's name, so it has one.

Try it

  1. Install the branch: cd ~/herdr-agent-threads-try && git fetch && git checkout agents-agy-amp && git pull && ./install.sh
  2. Run agy in a Herdr terminal, send one prompt, and press Cmd-Shift-T. The badge shows the Antigravity mark, and the turn shows its tokens, time, model and level, and tool count.
  3. Send a second prompt in agy. It shows up in Threads within a few seconds.
  4. Run amp in another terminal and press Cmd-Shift-T. Threads says "Amp isn't supported" with the reason, and Why Amp isn't supported opens the README section.
  5. Open Threads beside Codex, OpenCode, Pi or Cursor to see their marks in the badge.
  6. To go back to the chat look afterwards: git checkout chat-look && git pull && ./install.sh
