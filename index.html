Agent Threads, branch pinning. Not merged. Click any picture for full size. Arrow keys step through, Esc closes.

How these were taken. An isolated Herdr 0.1.13 window on the mini, driven by Herdr's mod commands. No real key press, click, hover or drag has reached this build yet, so those checks are yours. A cloud browser recording is not possible here, because this is a desktop app and not a web page. The small timing text in the header is the debug mode the pictures were taken in. It does not show in normal use.

A correction. The design page said reply selection was not affected by drawing a reply a paragraph at a time. That was wrong. On Herdr 0.1.13 and newer you can drag across a formatted reply, and a drag cannot cross separate list items. So only a block taller than the pane is split. A block that fits stays whole: a drag works across its paragraphs, and a return lands at the start of that block instead of on the paragraph. In a split block a drag stops at the end of the paragraph, and s still selects everything.
