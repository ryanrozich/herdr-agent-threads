Clickable header status, no header pin button

A click on the agent's state in the header (Working, Needs you, Done or Exited) now goes to the terminal, as t does. The list's header drops its pin icon, so the session title gets the room. Shots are of the synthetic acme-web session in an isolated test window, with debug off. Before is main at 3e2f836; after is this branch. The hover and the click could not be driven in that window, because its Herdr build has no synthetic pointer, so unit tests cover them and they are the first thing to check by hand. Click any shot to open it full size; arrow keys step through them and Esc closes.

What to test

  1. Install. cd ~/herdr-agent-threads-try && git fetch && git checkout header-status && git pull && ./install.sh
  2. Hover the state. In a Threads pane at least 440 px wide, hover the dot and word beside the Claude badge (Working, Needs you, Done or Exited). The cursor turns to a pointer, the chip gets the hover fill the header buttons have, and the tooltip ends "click to go to the terminal (t)".
  3. Click it. Click the state, best while it says Needs you. The terminal beside Threads gets the keyboard and a toast says "Focused t…", exactly as t does.
  4. Narrow pane. Make Threads narrower than 440 px, where the state is a dot on the badge's corner. Hover the badge: its tooltip starts with the state, then "click to go to the terminal (t)". A click on the badge gives the terminal the keyboard. With no state to show, the badge has no click.
  5. No pin icon in the list's header. The list's header has no pin icon any more, and the session title shows more of itself. p and the pin on an open turn's top line still pin.
  6. Pinned keeps its pin. The Pinned column's header, and the Pinned view in the same pane from 300 px, still have a pin button. It unpins the selected pin.
