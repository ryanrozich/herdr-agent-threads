Level 3: each call's command and output, read when you open it

Level 2 (PR 33) beside level 3 (PR 34, Claude Code). PRs 35 to 38 add the same for Codex, Pi, OpenCode and Antigravity. All shots come from Herdr 0.1.15 in an isolated test window on the mini, running each branch's mod on a synthetic acme-web session (made-up prompts, replies, files and tool output). The panel is 560 px wide and the shots are cropped to it. Click any shot to open it full size; the arrow keys step through them and Esc closes.

What to try

  1. Install the stack top. cd ~/herdr-agent-threads-try && git fetch && git checkout level-3-antigravity && ./install.sh (PR 38, which holds 29 to 37 too).
  2. Open a group. Click a group line, or press → on a turn until it opens. Only then does the panel read that group's calls from the transcript: each call's command, file, pattern or query, and how long it took. What it reads stays in memory and is never written anywhere.
  3. Open a call. Click a call to see its output: 12 lines first, then "Show all N lines" (up to 400). → once more opens every output in the open groups; ← closes the outputs first, then the groups.
  4. A failed call has a red icon. Its output shows what the tool returned, such as "Exit code 1" and the failing test.
  5. A group of one call shows that call's own row once opened.
  6. While a turn runs, its running group's line names the command running now, and that command's output box says "Running…" until the result lands.
  7. Other agents. Try a Codex, Pi, OpenCode or Antigravity session the same way. Cursor stays at tool names: its transcripts record no call ids and no output.

Notes on the shots

  • A group's line can only show a failed call once the group has been opened, because calls are read on open. Before that, turn 6's group reads "Ran 1 command" with a check.
  • Every synthetic call took 2 s, so each row says "2s".
  • The keys come from the panel's own commands (the same ones → and ← run), sent to the test window. The Show all click uses the panel's test-only click command.
  • The panel's test-only timing chip is hidden in these shots so the header looks as it does for you. Nothing else in the mod was changed.
