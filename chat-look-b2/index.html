Level 2: steps and groups in order, and the arrow keys

Level 1 (PR 32) beside level 2 (PR 33). All shots come from Herdr 0.1.15 in an isolated test window on the mini, running each branch's mod on a synthetic acme-web session (made-up prompts, replies and tool output). The session's last turn is running. The panel is 560 px wide and the shots are cropped to it. Click any shot to open it full size; the arrow keys step through them and Esc closes.

What to try

  1. Install. cd ~/herdr-agent-threads-try && git fetch && git checkout level-2 && ./install.sh (PR 33, which holds 29 to 32 too).
  2. Go deeper with →. On a selected turn, → opens the turn and its "Worked for" line, then every group under it. ← closes them again, one level at a time, then the line, then the turn.
  3. Read the steps. An open line lists what the agent did in order: a group of tool calls, anything it said in between, the next group. A group's line says what it did ("Read 4 files and edited 2 files"), and opened it names each call.
  4. The running turn. Its line is open by default. The group still going says so ("Searching 1 time, reading 2 files and running 1 command") with a spinner, and a "Working…" line ends the turn.

Notes on the shots

  • Level 2 names each call by its tool only (Read, Edit, Bash). The file, command and output of each call come with level 3, in the next batch.
  • A group's line leads with the tool icon, not a check. Level 2 never reads a call's result, so it cannot know the calls passed.
  • The keys come from the panel's own commands (the same ones → and ← run), sent to the test window. Clicks on the line use the panel's test-only click command.
  • The panel's test-only timing chip is hidden in these shots so the header looks as it does for you. Nothing else in the mod was changed.
