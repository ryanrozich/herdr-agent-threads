Design-review picks: pin numbers, agent state, one-row footer

Four items from the design review, on the synthetic acme-web session. Before is main at aefe6f4; after is this branch. Click any shot to open it full size; arrow keys step through them and Esc closes.

What to test

  1. Pin numbers. Pin two turns with p. Each pinned row in the list shows the pin and its number (1, 2), the same number the Pinned column and the digit keys use. Open one with Enter: the open turn's header shows it too.
  2. Antigravity in the notice. Focus a plain shell terminal (no agent) and press Cmd-Shift-T. The notice reads “Focus a Claude Code, Codex, OpenCode, Pi, Cursor or Antigravity terminal first”.
  3. Claude Code's state. Send Claude a prompt and scroll up into an older reply. The header says Working, then Done when it finishes. Ask for something that needs a permission prompt: the header says Needs you in red. Exit claude: Exited.
  4. An agent with no status. Open Threads beside Codex (or OpenCode, Pi, Cursor, Antigravity). After a turn ends the header says Done. While a turn runs it shows no word, rather than guess between working and waiting on an approval.
  5. The new-reply dot. Select an older turn so the list scrolls up, then let Claude answer a new prompt. The double-chevron button in the header gets a dot. Press End or scroll to the bottom: the dot goes. In a pane under 440 px the button appears only while it has the dot.
  6. One-row footer. The footer is one row: move, open, copy, quote, filter, pin, ? keys. Drag the pane narrower: hints drop from the right, and ? keys stays.
  7. The ? sheet. Press ?. A sheet lists every key in List, Open turn, Pins and View. Esc or ? closes it, and so does a click on ? keys in the footer, the close button or outside the card. With the search field focused, ? types a question mark.
  8. The Pinned column. With pins, the column's footer is the same single row: next pin, open, copy, quote, unpin, ? keys (narrower columns keep what fits).
