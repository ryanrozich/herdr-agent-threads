Images in a running turn

You pasted an image in Codex and Threads showed none. Codex records it the way Threads reads it. The pane left the tiles out of a turn the agent is still working on, for every agent, so the image came only when the turn ended, which in a long Codex turn is minutes later. Draft PR 14 shows the tiles while the turn runs, and a click on one opens the viewer. Nothing merges until you say so.

Before and after

The same running Codex turn. On main the bubble shows [Image #1] and no image. With the fix its tile sits over the message while Codex works.

A click on the tile

In a running turn a click on a tile opens the viewer at that image. A click beside the tiles selects the turn. Once the turn ends it behaves as before: open it, click a tile for the larger image, click that for the viewer.

What I found

  • Your Codex session (by field shape only) has the image twice: as data on the message line, and as the path of a temporary file (codex-clipboard-….png) on the prompt event. Threads decodes the data, so a deleted temporary file does not matter.
  • In your session the reader and decoder both found the image. The image cache had no Codex folder, because the turn was still running and the running row never asked for its images.
  • Other agents: Claude Code and OpenCode record pasted images and show them. Pi shows them while the temporary file it saved is still there, and otherwise says the image is gone. Cursor writes the word [Image] and keeps no image. Antigravity keeps none the pane can read. The fix applies to every agent's running turn.
  • Not checked with a real click or key: the test window cannot press, so the press runs through the pane's debug click, as for the viewer in PR 11.

Try it

  1. cd ~/herdr-agent-threads-try && git fetch && git checkout live-images && git pull && ./install.sh
  2. In a Codex terminal with Threads open, paste an image into a prompt that will take Codex a while, and send it.
  3. While Codex works, the tile shows over your message in Threads. Click it: the viewer fills the window. Esc closes.
  4. When the turn ends, open it: a click on the tile shows the image larger, and a click on that opens the viewer, as before.
