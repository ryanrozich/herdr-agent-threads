The strip under a reply is copy and quote only

Real frames from Herdr 0.1.15 in an isolated test window on the mini. The session is synthetic. Both builds get the same presses: select turn #7 and open it. Click any frame to open it full size. The arrow keys step through them and Esc closes.

What changed

  • The select icon (text cursor) and the terminal icon leave the strip under a reply. Copy and quote stay, in the same places.
  • The s key, the t key and Select view are unchanged.
  • On Herdr before 0.1.13, where the formatted reply cannot be selected, the select icon stays after quote as the way there by mouse. The test window runs 0.1.15, so that case is covered by a test, not a frame.
  • The strip's click positions follow the new layout: a press where select or terminal used to be does nothing.
  • The usage page and RECIPE say the same. The ? sheet already listed s and t as keys and is unchanged.
  • No notice or hint appears anywhere.
